Hornet Bot lives in the club Discord server and handles the small annoying
jobs nobody wants to do by hand.

Right now it can post a reminder before every meeting. Next up is a `!idea`
command that saves project ideas to a list so good ones do not disappear into
the chat history two minutes after somebody says them.

**Good first task:** add a new command. Every command is about ten lines of
Python, and there is a template in the repository to copy.
