Every page here is built from files in our repository. When somebody merges a
change, GitHub rebuilds the whole site and publishes it in about a minute,
with no uploading and no server to pay for.

The useful part: adding a project to the Build page means writing one Markdown
file, which you can do from the GitHub website on a Chromebook. You do not have
to install anything or understand the layout code to contribute.

**Good first task:** add your own project here, or fix a typo you spot on any
page. See `CONTRIBUTING.md` in the repository.
